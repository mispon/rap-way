# Rap Way Reference Image Prompts

These prompts document the built-in image-generation requests used for accepted or proposed visual references. They are provenance records and starting points, not immutable production prompts.

## Home-studio mood reference v1

```text
Use case: stylized-concept
Asset type: preview-only visual direction mood art for a mobile 2D rap career simulator
Primary request: Create an original key-art illustration demonstrating a timeless contemporary city with a warm late-1990s/early-2000s hip-hop and R&B flow, presented as a modern music editorial / street-zine collage.
Input images: Image 1 is compatibility reference only for the clean comic linework, flat cel shading, approachable cartoon proportions, and character rendering density. Do not reproduce any pictured character, pose, logo, layout, clothing combination, or text.
Scene/backdrop: A fictional young unknown rapper in a cramped modest apartment home studio at dusk, writing lyrics beside a cheap microphone and second-hand laptop; outside the window is a lived-in city neighborhood with buses, small shops, utility wires, posters, and distant venue lights. Subtle hints of a courier bag and unopened bills suggest the start of a career.
Subject: One entirely original fictional young adult musician, grounded and aspirational rather than glamorous or threatening.
Style/medium: polished 2D comic illustration integrated with music-magazine editorial collage; crisp black contour, flat color blocks, selective soft shadows, cut-paper edges, restrained halftone and paper grain, small sticker/tape accents.
Composition/framing: vertical 9:16 mobile key art, character and microphone in the lower-middle, city and evening sky opening upward, strong readable silhouette, no UI overlay.
Lighting/mood: warm sunset and dim amber room light, calm reflective ambition, slightly nostalgic but clearly contemporary.
Color palette: deep graphite, warm off-white, faded olive green, burnt orange, muted burgundy, with one restrained electric coral-red accent.
Materials/textures: subtle recycled paper, screen-print ink, halftone shadows; keep faces and important objects clean.
Constraints: visually compatible beside CharacterCreator2D characters; modern smartphone and laptop may appear subtly; original fictional world; no brand marks; no readable text; no logos; no watermark.
Avoid: photorealism, 3D render, anime, cyberpunk neon, luxury gold, gangster caricature, excessive graffiti, heavy VHS distortion, grimdark violence, clutter, copied GTA imagery.
```

## Early home screen reference v1

```text
Use case: ui-mockup
Asset type: high-fidelity portrait mobile game reference screen, visual design guide artifact
Primary request: Design one coherent early-career HOME screen for a text-heavy 2D rap career simulator. It must demonstrate the accepted modern music-editorial / street-zine style with restrained late-1990s/early-2000s analog warmth, while remaining a clean contemporary mobile interface.
Input images: Image 1 is a compatibility reference only for CharacterCreator2D's clean comic linework, flat cel shading, and character proportions; do not copy its characters, clothing combinations, layout, logo, or text. Image 2 is the accepted mood reference for palette, atmosphere, paper collage, home-studio subject matter, and city warmth; simplify its background detail for gameplay readability and do not reproduce its exact composition.
Screen structure: portrait 9:16. Dark graphite app shell. Compact top HUD with date/time and six clearly separated resources. Main middle area is an illustrated static tableau of a cramped first apartment/home studio with one entirely original young musician in CharacterCreator2D-compatible full-body comic style, cheap microphone, second-hand laptop, courier bag, bills, small window, modest speaker. Overlay only subtle selection affordances, not hidden-object hotspots. Lower action sheet uses warm off-white paper cards. Persistent four-item bottom navigation.
Exact Russian UI text, render verbatim where feasible:
Top: "12 ИЮНЯ · 08:00"
Resource labels: "ЭНЕРГИЯ", "СЫТОСТЬ", "МОТИВАЦИЯ", "ДЕНЬГИ", "ФАНАТЫ", "ХАЙП"
Location: "ДОМ"
Primary actions: "ОТДОХНУТЬ", "ПИСАТЬ ТЕКСТ", "ВЫЙТИ В ГОРОД"
Small news card: "ПЕРВЫЙ ШАНС" and "В дешёвой студии освободилось окно."
Bottom navigation: "ДОМ", "КАРТА", "КАРЬЕРА", "НОВОСТИ"
Style/medium: polished mobile UI mockup plus 2D comic tableau; crisp outlines; flat color blocks; subtle shadows; restrained halftone, recycled-paper grain, cut-paper edges, tape/sticker details only in decorative zones.
Information design: compact editorial density, strict underlying grid, clear primary action, large touch targets, progressive disclosure, readable at phone size. Full-body character in tableau, no portrait duplicates. Utility resource icons are simple one-color screen-print shapes; rare decorative badge style is not needed here.
Color palette: graphite #181A1B, raised charcoal #242729, warm paper #F2E7D5, muted ink #202223, coral accent #F04F4A, faded olive #78815A, amber #D8943B, burgundy #7A3541. Use coral sparingly for main action/attention, not every control. Error red must not appear.
Typography direction: condensed heavy poster-style headings and numbers; clean modern Cyrillic sans serif body. Avoid graffiti in functional text.
Motion implication: composition should feel ready for quick card-slide and paper-snap transitions, but this image is static.
Constraints: no phone device frame; no brand marks; no watermark; no English UI; no photorealism; no 3D; no luxury cues; no cyberpunk neon; no casino effects; no excessive graffiti; no tiny illegible controls; no lorem ipsum; no copied GTA imagery. If exact long text is difficult, prioritize accurate hierarchy and keep all other text minimal rather than inventing gibberish.
```
